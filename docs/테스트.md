# 테스트 문서

> 실행일: 2026-10-01 · 결과: **94개 전부 통과** (단위 67 + 통합 27) · `./gradlew test` → `BUILD SUCCESSFUL`

## 실행 방법

```bash
docker compose up -d   # 통합 테스트가 로컬 PostgreSQL(55432)을 사용
./gradlew test
```

- 통합 테스트는 compose PostgreSQL에 **테스트 전용 `fileupload_test` DB를 자동 생성**하고
  `schema.sql`을 그대로 적용합니다 — 운영 데이터와 분리되면서 DB CHECK/UNIQUE 제약까지 함께 검증.
- 매 테스트 전 데이터 초기화(고정 확장자 unCheck 복원, 커스텀/기록/차단 삭제).
- Testcontainers가 아닌 compose DB를 쓰는 이유: 이 환경의 Docker Engine 29.x와
  docker-java 호환 문제 (PROMPT_LOG.md 3-2).

### UploadFlowIntegrationTest (11) — 업로드 종단

**다중 파일 한 요청(10개) 부분 성공** — 파일별 독립 판정:

| # | 파일 | 결과 |
|---|---|---|
| 1 | `setup.EXE` | `BLOCKED_EXTENSION` (대소문자 우회 차단) |
| 2 | `script.sh` (커스텀) | `BLOCKED_EXTENSION` |
| 3 | `file.exe.txt` | `BLOCKED_INNER_EXTENSION` |
| 4 | `com.example.config.txt` | STORED (첫 세그먼트 제외) |
| 5 | 진짜 PNG | STORED + INLINE |
| 6 | `fake.jpg` (PNG 내용) | `CONTENT_MISMATCH` |
| 7 | `backdoor` (무확장자 ELF) | `EXECUTABLE_DETECTED` |
| 8 | `/Launch` PDF | `ACTIVE_CONTENT` |
| 9 | `.env` | STORED + `_.env` 재부여 안내 |
| 10 | zip 안의 `a.exe` | `BLOCKED_EXTENSION` |

그 외: **정책 변경 전후 같은 파일의 판정 변화**(exe 미차단 STORED → 차단 후 REJECTED — 정책이
실제로 강제되는 증거) · 신뢰 목록 jpg도 커스텀 차단이 이김(차단 우선) · 7z/tar.gz/중첩 zip 거부 ·
11개 업로드 `TOO_MANY_FILES` · 다운로드 헤더(비신뢰 octet-stream+attachment+nosniff,
한글 파일명 RFC 5987, 신뢰 PNG inline) · 판정 기록·위반 점수 DB 저장 ·
한글 86자/무확장자 README/**MZ세대 설문.txt 오탐 없음**

결함 수정으로 추가(docs/결함보고.md): **확장자 21자·300자 이름**은 500이 아니라 파일별 `INVALID_FILENAME`으로 기록되고 같은 요청의 정상 파일은 STORED ·
**`.jpeg`는 이름 유지 + 변환 안내 없음**(다운로드 `image/jpeg`, `photo.jpeg`) · **26MB 파일**은 요청 전체가 아니라 그 파일만 `SIZE_EXCEEDED`("25MB" 메시지), 함께 올린 파일은 STORED

### GuardIntegrationTest (3) — 요청 단위 필터

### ErrorResponseIntegrationTest (4) — 오류 응답 형식

클라이언트 실수는 500이 아니라 400/404/405로 응답하고 형식은 `{code, message, detail?}` (명세 15장):

| 시나리오 | 검증 |
|---|---|
| 빈 JSON 본문(`@NotNull`), `@Size(max=100)` 초과 | 400 `INVALID_REQUEST` + `detail.{필드}` 메시지 |
| 깨진 JSON, UUID가 아닌 `publicId` | 400 `INVALID_REQUEST` |
| `files` 파트 없음, 멀티파트가 아닌 POST | 400 `NO_FILES` |
| 없는 경로, 허용되지 않은 메서드 | 404 `NOT_FOUND`, 405 `METHOD_NOT_ALLOWED` |
